### Sobre

Construo aplicações web completas e experiências interativas unindo arquitetura de software e fluxos de desenvolvimento assistidos por Inteligência Artificial. Foco em transformar ideias em produtos funcionais com agilidade — da estruturação de dados no back-end à renderização 3D e micro-interações no front-end.

### Stack & Ferramentas

**Desenvolvimento & Arquitetura**
- TypeScript, JavaScript, React, Next.js, Tailwind CSS
- Node.js, PostgreSQL (Neon), Supabase, Firebase, SQLite

**3D, Interatividade & Prototipagem**
- Three.js / WebGL, GSAP, Lenis, Blender, Godot 4

**Fluxo com IA**
- Orquestração de agentes de código, prototipagem rápida guiada por prompts e automação via MCP (Model Context Protocol).
